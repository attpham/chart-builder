# Chart Builder

A Canva-like chart builder web application for creating beautiful, fully customizable charts and graphs. Export as editable PowerPoint charts or SVG files.

## Features
- 7 chart types: Bar, Horizontal Bar, Stacked Bar, Line, Area, Pie, Donut
- Real-time chart customization
- Color palettes and per-series color control
- Font customization (family, size, bold, italic)
- Chart-specific styling (bar radius, line tension, donut cutout, etc.)
- Data editor with add/remove rows and series
- Export as native editable PowerPoint chart (.pptx)
- Export as SVG file

## Setup

npm install
npm run dev

Open http://localhost:5173 in your browser.

## Build

npm run build
npm run preview
